# Screenshots

This directory contains screenshots of AgentBoard CE for the README and documentation.

## Suggested Screenshots

Take these screenshots while running the app locally (`npm run dev`) in English:

1. **dashboard.png** — The main dashboard showing project stats, quick actions, and recent drafts
2. **projects.png** — The projects list with seeded demo projects
3. **command-runner.png** — The terminal/command runner page with a command executed
4. **agents.png** — The agent profiles library showing the default profiles
5. **issue-triage.png** — The issue triage page with a generated draft
6. **pr-review.png** — The PR review page with a generated review
7. **release-notes.png** — The release notes page
8. **settings.png** — The settings page showing language selector and theme options

## Tips

- Use light mode for primary screenshots, dark mode for an alternate set
- Use a clean browser window (no extensions visible)
- Ensure the sidebar is visible and expanded
- Make sure the UI is in English
- Use a standard window size (1280x800 or 1440x900)
