# Roadmap

This document outlines the planned features and improvements for AgentBoard CE.

## v0.1.0 — Local MVP and Open-Source Release

- [x] Dashboard with overview statistics
- [x] Project registry with CRUD operations
- [x] Command templates with categories
- [x] Terminal workspace with command execution
- [x] Agent profiles library (8 default profiles)
- [x] Issue triage workspace
- [x] PR review workspace
- [x] Release notes generator
- [x] Settings page (theme, language, project defaults)
- [x] Data export/import
- [x] Multilingual UI (English, Simplified Chinese, Russian)
- [x] Local-first architecture with SQLite
- [x] Dark mode support
- [x] Dangerous command detection and confirmation
- [x] Open-source documentation and licensing

## v0.2.0 — Git Status and Local Repository Insights

- [x] Git status display per project
- [x] Branch information display
- [x] Recent commit history
- [x] Remote origin URL display
- [x] Modified, staged, and untracked file lists
- [x] Copy Git Summary for AI coding tools
- [x] Refresh Git Status button
- [ ] Diff viewer for uncommitted changes
- [ ] Local branch management
- [ ] Merge conflict detection

## v0.3.0 — GitHub Issues and Pull Requests Integration

- [x] GitHub API integration
- [x] Import issues from GitHub repositories
- [x] Fetch and browse pull requests
- [x] Pull request detail with changed files and commits
- [x] Create local PR Review Draft from GitHub PR
- [x] Copy PR Markdown and review checklist
- [x] Create issues from triage drafts
- [ ] Post PR review comments to GitHub
- [ ] Repository webhook support
- [ ] CI/CD status display

## v0.4.0 — Codex/OpenAI Maintainer Workflows

- [ ] OpenAI API integration for issue triage
- [ ] AI-assisted PR review with risk assessment
- [ ] Test failure analysis and suggestions
- [ ] Release notes generation from git history
- [ ] Documentation update suggestions
- [ ] Code quality checks and refactoring plans
- [ ] Maintainer automation workflows

See [docs/codex-workflows.md](codex-workflows.md) for detailed plans.

## v0.5.0 — Desktop Packaging

- [ ] Tauri or Electron desktop app
- [ ] System tray integration
- [ ] Global keyboard shortcuts
- [ ] Native notifications
- [ ] Auto-update mechanism
- [ ] Cross-platform packaging (macOS, Windows, Linux)

## v1.0.0 — Stable Local-First Maintainer Workspace

- [ ] Stable API
- [ ] Plugin system
- [ ] Custom workflows
- [ ] Terminal with xterm.js and node-pty
- [ ] Performance optimizations
- [ ] Comprehensive test coverage
- [ ] Full documentation
