# Screenshots Guide

This document explains how to take screenshots of AgentBoard CE for the README and documentation.

## Setup

1. Start the development server:
   ```bash
   npm run dev
   ```

2. Open http://localhost:3000 in your browser

3. Use a clean browser window (no extensions visible, no bookmarks bar)

4. Set window size to 1280x800 or 1440x900

## Required Screenshots

### 1. Dashboard (`dashboard.png`)
- Navigate to the Dashboard page
- Ensure the sidebar is visible and expanded
- Shows project stats, quick actions, and recent drafts
- Use light mode

### 2. Projects (`projects.png`)
- Navigate to the Projects page
- Shows the list of seeded demo projects
- Use light mode

### 3. Command Runner (`command-runner.png`)
- Navigate to the Terminal page
- Select a project and run a command
- Shows command output
- Use light mode

### 4. Agent Profiles (`agents.png`)
- Navigate to the Agents page
- Shows the list of default agent profiles
- Use light mode

### 5. Issue Triage (`issue-triage.png`)
- Navigate to Issue Triage
- Create or view a triage draft
- Shows the generated triage output
- Use light mode

### 6. PR Review (`pr-review.png`)
- Navigate to PR Review
- Create or view a review draft
- Shows the generated review output
- Use light mode

### 7. Settings (`settings.png`)
- Navigate to Settings
- Shows language selector and theme options
- Use light mode

## Optional Screenshots

### Dark Mode Variants
- Take the same screenshots in dark mode
- Name them `dashboard-dark.png`, `projects-dark.png`, etc.

### Language Variants
- Take screenshots in Chinese and Russian
- Name them `dashboard-zh.png`, `dashboard-ru.png`, etc.

## Tips

- Ensure the UI is in English for primary screenshots
- Make sure no personal data or private paths are visible
- Use the seeded demo data
- Crop appropriately — no browser chrome needed
- Save as PNG for best quality
